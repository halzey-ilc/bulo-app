# Сборка APK

Сборка идёт локально через Gradle. Папка `apps/mobile/android` создаётся командой `expo prebuild` и в git не хранится.

## Что нужно

- JDK 17
- Android SDK с NDK и CMake (Gradle докачает нужные версии сам, если приняты лицензии)
- Node.js 22
- Около 6 ГБ на диске под SDK и кэш Gradle

```bash
export JAVA_HOME=/путь/к/jdk-17
export ANDROID_HOME=/путь/к/android-sdk
```

## Сборка

Адрес API встраивается в приложение при сборке:

```bash
cd apps/mobile
export EXPO_PUBLIC_API_URL=https://ваш-сервер/api NODE_ENV=production CI=1
npx expo prebuild --platform android --no-install
cd android
./gradlew assembleRelease --no-daemon --console=plain --max-workers=2 -x lint
```

Готовый файл: `apps/mobile/android/app/build/outputs/apk/release/app-release.apk`.

В сборке две архитектуры: `arm64-v8a` для телефонов и `x86_64` для эмулятора.

## Если мало памяти

В WSL по умолчанию доступна половина памяти Windows. На 16 ГБ этого мало: без ограничений компиляция C++ забивает память и своп, WSL перестаёт принимать команды (`WSAETIMEDOUT`), а лог Gradle часами молчит. Тишина в логе в этом случае не значит, что сборка зависла.

Что помогает:

1. Остановить API, Expo, админку и эмулятор на время сборки.
2. Задать `--max-workers=2`.
3. Ограничить `ninja`: переименовать `$ANDROID_HOME/cmake/<версия>/bin/ninja` в `ninja.real` и положить на его место скрипт:

   ```sh
   #!/bin/sh
   exec "$0.real" -j3 "$@"
   ```

С этими настройками полная сборка занимает около 20 минут, а повторная после правок только в JS меньше 15.

## Адрес сервера в приложении

Адрес можно поменять без пересборки: на экране входа зажмите логотип BULO примерно на секунду, введите адрес и нажмите «Сохранить». Приложение проверит, что сервер отвечает. Пустое поле возвращает адрес из сборки.

## Тест на телефоне через туннель

Телефон не видит `localhost` компьютера, поэтому для быстрого показа API открывают временным туннелем:

```bash
cloudflared tunnel --no-autoupdate --url http://127.0.0.1:4000
```

Адрес вида `https://....trycloudflare.com` введите на экране «Сервер». Он работает, пока запущен процесс, и меняется при каждом перезапуске.

Бесплатные туннели localhost.run и serveo для этого не подходят: первый быстро меняет адрес, второй закрывается примерно через 10 минут.

**Безопасность.** Через туннель API доступен всем, кто знает адрес. При `DEV_RETURN_OTP=true` код входа приходит прямо в ответе API, поэтому войти под номером партнёра может кто угодно. Не вносите реальные данные и закрывайте туннель после показа.

## Подпись

Шаблон Expo подписывает релизную сборку отладочным ключом. Для установки на телефон этого достаточно, для Google Play нужен свой ключ и файл AAB (`./gradlew bundleRelease`).
